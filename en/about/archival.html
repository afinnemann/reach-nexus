Archival plan

REACH Nexus is a five-year project, ending on 31 December 2030. We are planning the end now, while we still have the resources to do it well. Static project websites rot quietly; consortium sites rot loudly. This page sets out what will happen.

Annual snapshots

Each year, the published website is tagged in git, deposited as a release in the project Zenodo community, and assigned a DOI. The CITATION.cff file is updated each release so the citation always points to the most recent stable version.

End of grant (December 2030)

  • A final tagged release of the website is deposited to Zenodo with a permanent DOI.
  • Open data and code are deposited via the Repositories listed in the Data & FAIR page.
  • Restricted data follow the access controls set out in their data-management plans, retained at the host institution for the period required by law and ethics approval.
  • The live website remains online for at least three years after the project ends, hosted by the University of Amsterdam. After that, traffic is redirected to the final Zenodo deposit so that links from publications remain resolvable.

Long-term institutional record

A summary report of the project — outcomes, lessons, and the consortium's accountability to the four communities — is deposited at NWO/FAPESP, the host institutional repositories, and at the partner organisations Instituto Alana and Fiocruz Amazônia.
