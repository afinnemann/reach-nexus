Accessibility

REACH Nexus aims for WCAG 2.2 Level AA across this website. We treat accessibility as part of the build, not as a retrofit.

What we do

  • Semantic HTML landmarks (header, main, nav, footer) on every page.
  • A "skip to main content" link as the first focusable element.
  • Visible focus rings on every interactive element. Focus order follows reading order.
  • Colour-contrast budget: ≥ 4.5:1 for body text, ≥ 3:1 for large text and non-text UI components.
  • prefers-reduced-motion respected — no animations beyond the user's preference.
  • The map page works with JavaScript disabled — a text list of the four sites is shown when the map cannot render.
  • No colour-only signalling: every status conveyed by colour is also conveyed by text or shape.
  • Lighthouse and pa11y-ci checks run on every change to the codebase.

Known issues

  • Team-member photos are not yet present; placeholder initials may not convey personhood as warmly as a photograph would. We are working on this.
  • Some Portuguese pages are still in placeholder form pending review by the Portuguese editorial owner.

Report an accessibility issue

If you encounter content that is hard or impossible to use with assistive technology, please email info@reach-nexus.org with the page URL and a description of what went wrong. We aim to acknowledge accessibility reports within 5 working days and to fix issues within 20.
