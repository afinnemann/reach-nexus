{# Accessibility statement #}

{% if lang == "en" %}Accessibility{% else %}Acessibilidade{% endif %}

{% if lang == "en" %}REACH Nexus aims for WCAG 2.2 Level AA across this website. We treat accessibility as part of the build, not as a retrofit.{% else %}O REACH Nexus busca o cumprimento das diretrizes WCAG 2.2 Nível AA em todo este site. Tratamos a acessibilidade como parte da construção, não como adaptação posterior.{% endif %}

{% if lang == "en" %}What we do{% else %}O que fazemos{% endif %}

  • {% if lang == "en" %}Semantic HTML landmarks (header, main, nav, footer) on every page.{% else %}Marcações HTML semânticas (header, main, nav, footer) em todas as páginas.{% endif %}
  • {% if lang == "en" %}A "skip to main content" link as the first focusable element.{% else %}Um link "pular para o conteúdo principal" como primeiro elemento focável.{% endif %}
  • {% if lang == "en" %}Visible focus rings on every interactive element. Focus order follows reading order.{% else %}Anéis de foco visíveis em todos os elementos interativos. A ordem de foco segue a ordem de leitura.{% endif %}
  • {% if lang == "en" %}Colour-contrast budget: ≥ 4.5:1 for body text, ≥ 3:1 for large text and non-text UI components.{% else %}Limite de contraste: ≥ 4,5:1 para texto corrido, ≥ 3:1 para texto grande e componentes não-textuais.{% endif %}
  • {% if lang == "en" %}prefers-reduced-motion respected — no animations beyond the user's preference.{% else %}prefers-reduced-motion respeitado — sem animações além da preferência do usuário.{% endif %}
  • {% if lang == "en" %}The map page works with JavaScript disabled — a text list of the four sites is shown when the map cannot render.{% else %}A página de mapa funciona com JavaScript desativado — uma lista textual dos quatro sítios é exibida quando o mapa não pode renderizar.{% endif %}
  • {% if lang == "en" %}No colour-only signalling: every status conveyed by colour is also conveyed by text or shape.{% else %}Sem sinalização baseada apenas em cor: todo status transmitido por cor também é transmitido por texto ou forma.{% endif %}
  • {% if lang == "en" %}Lighthouse and pa11y-ci checks run on every change to the codebase.{% else %}Verificações Lighthouse e pa11y-ci são executadas a cada mudança no código.{% endif %}

{% if lang == "en" %}Known issues{% else %}Problemas conhecidos{% endif %}

  • {% if lang == "en" %}Team-member photos are not yet present; placeholder initials may not convey personhood as warmly as a photograph would. We are working on this.{% else %}Fotos dos membros da equipe ainda não estão presentes; iniciais provisórias podem não transmitir a presença pessoal tão calorosamente quanto uma fotografia. Estamos trabalhando nisso.{% endif %}
  • {% if lang == "en" %}Some Portuguese pages are still in placeholder form pending review by the Portuguese editorial owner.{% else %}Algumas páginas em português ainda estão em forma provisória, aguardando revisão pela responsável editorial em português.{% endif %}
