{% if lang == "en" %}Consortium structure{% else %}Estrutura do consórcio{% endif %}

{% if lang == "en" %}REACH Nexus is co-led by Reinout Wiers (UvA) and Leandro Giatti (USP). The two PIs share equal authority over the project. The day-to-day work is organised across five work packages, each with a named lead drawn from the co-applicant team.{% else %}O REACH Nexus é co-liderado por Reinout Wiers (UvA) e Leandro Giatti (USP). Os dois PIs compartilham autoridade equivalente sobre o projeto. O trabalho cotidiano é organizado em cinco pacotes de trabalho, cada um com uma liderança nomeada entre os co-proponentes.{% endif %}

{% if lang == "en" %}Decision-making bodies{% else %}Órgãos de decisão{% endif %}

  • {% if lang == "en" %}Management Committee{% else %}Comitê Gestor{% endif %} — {% if lang == "en" %}the two PIs plus the WP leads. Meets monthly. Decides on scope, budget, and cross-WP dependencies.{% else %}os dois PIs e líderes de WP. Reúne-se mensalmente. Decide sobre escopo, orçamento e dependências entre WPs.{% endif %}
  • {% if lang == "en" %}Thematic Committees{% else %}Comitês Temáticos{% endif %} — {% if lang == "en" %}domain-specific groups (modelling, health systems, citizen science, urban planning, ethics) that surface technical decisions to the Management Committee.{% else %}grupos temáticos (modelagem, sistemas de saúde, ciência cidadã, planejamento urbano, ética) que levam decisões técnicas ao Comitê Gestor.{% endif %}
  • {% if lang == "en" %}Advisory Board{% else %}Conselho Consultivo{% endif %} — {% if lang == "en" %}external advisors from public health, environmental science, urban governance, and community-based organisations. Meets twice yearly.{% else %}consultores externos de saúde pública, ciência ambiental, governança urbana e organizações de base comunitária. Reúne-se duas vezes ao ano.{% endif %}
  • {% if lang == "en" %}Local Working Groups{% else %}Grupos de Trabalho Locais{% endif %} — {% if lang == "en" %}one per case site, with the local research lead, community partner, and at least one community representative. They hold veto over how their site appears publicly.{% else %}um por sítio, com o líder de pesquisa local, o parceiro comunitário e ao menos um representante da comunidade. Detêm direito de veto sobre a representação pública do seu sítio.{% endif %}
