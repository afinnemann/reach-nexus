{% if lang == "en" %}Data-management approach{% else %}Abordagem de gestão de dados{% endif %}

{% if lang == "en" %}REACH Nexus follows FAIR principles — Findable, Accessible, Interoperable, Reusable — within the constraints set by the ethics framework. Where community data sovereignty applies, accessibility is mediated through the relevant community partner and is not the consortium's unilateral decision.{% else %}O REACH Nexus segue os princípios FAIR — Encontráveis, Acessíveis, Interoperáveis, Reutilizáveis — dentro dos limites estabelecidos pelo arcabouço ético. Onde a soberania de dados comunitários se aplica, a acessibilidade é mediada pelo parceiro comunitário relevante e não é decisão unilateral do consórcio.{% endif %}

{% if lang == "en" %}Repositories{% else %}Repositórios{% endif %}

  • {% if lang == "en" %}Code: project GitHub organisation; mirrored to Zenodo on tagged release with a DOI.{% else %}Código: organização GitHub do projeto; espelhado no Zenodo a cada release marcada com DOI.{% endif %}
  • {% if lang == "en" %}Open data: Zenodo and DataverseNL (UvA), with DOIs.{% else %}Dados abertos: Zenodo e DataverseNL (UvA), com DOIs.{% endif %}
  • {% if lang == "en" %}Restricted data: held within the host institution; access by request through the data-access committee.{% else %}Dados restritos: mantidos na instituição anfitriã; acesso mediante solicitação ao comitê de acesso a dados.{% endif %}

{% if lang == "en" %}Embargo and access policy{% else %}Política de embargo e acesso{% endif %}

{% if lang == "en" %}Where journal embargoes apply, the metadata are released openly while the underlying article is under embargo. Accepted manuscripts are deposited in institutional green-OA repositories (UvA Pure, USP repositórios) on acceptance, with the publisher version released when permitted.{% else %}Onde houver embargo de periódico, os metadados são divulgados abertamente enquanto o artigo permanece sob embargo. Manuscritos aceitos são depositados em repositórios institucionais verdes (UvA Pure, repositórios USP) na aceitação, com a versão da editora liberada quando permitida.{% endif %}

{% if lang == "en" %}Indigenous and community data sovereignty{% else %}Soberania de dados indígenas e comunitários{% endif %}

{% if lang == "en" %}Data describing indigenous communities (Parque das Tribos) and informal-settlement residents (Jardim Pantanal) follow CARE principles — Collective benefit, Authority to control, Responsibility, Ethics — alongside FAIR. Geocoded community data are not opened publicly without prior agreement with the relevant partner.{% else %}Dados que descrevem comunidades indígenas (Parque das Tribos) e moradores de assentamento informal (Jardim Pantanal) seguem os princípios CARE — Benefício coletivo, Autoridade de controle, Responsabilidade, Ética — em paralelo aos FAIR. Dados georreferenciados de comunidades não são publicados abertamente sem acordo prévio com o parceiro relevante.{% endif %}
