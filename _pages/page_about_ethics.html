{% if lang == "en" %}Ethics{% else %}Ética{% endif %}

{% if lang == "en" %}The project works with people in vulnerable urban communities, including indigenous residents in Manaus and informal-settlement residents in São Paulo. Ethical conduct is not an add-on; it shapes who decides what is studied, how data are collected, and what is shown publicly.{% else %}O projeto trabalha com pessoas em comunidades urbanas vulneráveis, incluindo moradores indígenas em Manaus e moradores de assentamento informal em São Paulo. A conduta ética não é um complemento; ela define quem decide o que será estudado, como os dados são coletados e o que é exibido publicamente.{% endif %}

{% if lang == "en" %}Ethics review{% else %}Revisão ética{% endif %}

{% if lang == "en" %}Empirical work is reviewed by the institutional review boards of the host institutions in each jurisdiction — UvA Faculty of Social and Behavioural Sciences (and Amsterdam UMC where clinical data are involved) in the Netherlands; the Plataforma Brasil and the relevant CEP at USP / Fiocruz Amazônia in Brazil. Approval references will be listed here once issued.{% else %}O trabalho empírico é submetido aos comitês de ética das instituições anfitriãs em cada jurisdição — UvA Faculdade de Ciências Sociais e Comportamentais (e Amsterdam UMC quando há dados clínicos) nos Países Baixos; Plataforma Brasil e o CEP correspondente na USP / Fiocruz Amazônia no Brasil. Os números de aprovação serão listados aqui após emissão.{% endif %}

{% if lang == "en" %}Community-engagement principles{% else %}Princípios de engajamento comunitário{% endif %}

  • {% if lang == "en" %}Communities are co-researchers, not subjects. The Local Working Groups hold veto over what is studied at their site.{% else %}Comunidades são co-pesquisadoras, não objetos. Os Grupos de Trabalho Locais têm poder de veto sobre o que é estudado em seu sítio.{% endif %}
  • {% if lang == "en" %}Free, prior, and informed consent — collected at the right moments, in the right languages, in accessible formats — is the baseline.{% else %}O consentimento livre, prévio e informado — recolhido nos momentos certos, nos idiomas certos, em formatos acessíveis — é o piso.{% endif %}
  • {% if lang == "en" %}Findings are returned to communities in plain language before they are published academically.{% else %}Os achados são devolvidos às comunidades em linguagem simples antes de serem publicados academicamente.{% endif %}
  • {% if lang == "en" %}For Parque das Tribos, the project follows indigenous data-sovereignty principles agreed with the community association and Fiocruz Amazônia.{% else %}Para o Parque das Tribos, o projeto segue princípios de soberania de dados indígenas acordados com a associação comunitária e a Fiocruz Amazônia.{% endif %}

{% if lang == "en" %}Public representation of place{% else %}Representação pública dos lugares{% endif %}

{% if lang == "en" %}Every site page on this website opens with a short "How this place is shown here" block — what is shown, what deliberately is not, and who decided. This is a design pattern, not a policy buried in a back page. It is enforced in the data layer: the site map cannot render a marker without an explicit precision field signed off by the local partner.{% else %}Cada página de sítio neste site abre com um bloco curto "Como este local é representado aqui" — o que se mostra, o que deliberadamente não se mostra, e quem decidiu. É um padrão de design, não uma política enterrada em uma página secundária. É aplicado na camada de dados: o mapa não renderiza um marcador sem um campo explícito de precisão validado pelo parceiro local.{% endif %}
