{# Approach & references #}

{% if lang == "en" %}Approach & references{% else %}Abordagem e referências{% endif %}

{% if lang == "en" %}REACH Nexus brings together urban planning, public health, environmental law, clinical psychology, and systems modelling into a single comparative programme. The four cases are not just settings — they are the research design.{% else %}O REACH Nexus reúne planejamento urbano, saúde pública, direito ambiental, psicologia clínica e modelagem de sistemas em um único programa comparativo. Os quatro casos não são apenas cenários — são o desenho da pesquisa.{% endif %}

{% if lang == "en" %}Conceptual framing{% else %}Enquadramento conceitual{% endif %}

{% if lang == "en" %}The project takes a systems perspective on the polycrisis — the entanglement of climate change, urban inequality, and health-system fragility. We use planetary-health concepts in dialogue with emerging "nexus" frameworks, and we work backwards from cascading vulnerabilities to find intervention points that address root causes rather than symptoms.{% else %}O projeto adota uma perspectiva sistêmica sobre a policrise — o entrelaçamento entre mudança climática, desigualdade urbana e fragilidade do sistema de saúde. Usamos conceitos de saúde planetária em diálogo com arcabouços emergentes de "nexo", e trabalhamos a partir de vulnerabilidades em cascata para encontrar pontos de intervenção que tratem causas-raiz, não sintomas.{% endif %}

{% if lang == "en" %}Methods{% else %}Métodos{% endif %}

  • {% if lang == "en" %}Causal-loop diagrams and agent-based models{% else %}Diagramas de loops causais e modelos baseados em agentes{% endif %} ({% if lang == "en" %}WP2{% else %}WP2{% endif %}) — {% if lang == "en" %}site-specific structures, refined iteratively against citizen-science data.{% else %}estruturas específicas por sítio, refinadas iterativamente com dados de ciência cidadã.{% endif %}
  • {% if lang == "en" %}Health-system capacity assessment{% else %}Avaliação de capacidade do sistema de saúde{% endif %} ({% if lang == "en" %}WP3{% else %}WP3{% endif %}) — {% if lang == "en" %}secondary data on climate-sensitive disease, mental-health surveys after extreme events, primary-care assessments.{% else %}dados secundários sobre doenças climato-sensíveis, levantamentos de saúde mental após eventos extremos, avaliação de atenção primária.{% endif %}
  • {% if lang == "en" %}Citizen-science co-research{% else %}Co-pesquisa em ciência cidadã{% endif %} ({% if lang == "en" %}WP4{% else %}WP4{% endif %}) — {% if lang == "en" %}participatory workshops and mobile data-collection tools that capture lived experience during and after extreme weather.{% else %}oficinas participativas e ferramentas móveis de coleta que capturam a experiência vivida durante e após eventos climáticos extremos.{% endif %}
  • {% if lang == "en" %}Living-lab interventions{% else %}Intervenções em laboratórios vivos{% endif %} ({% if lang == "en" %}WP5{% else %}WP5{% endif %}) — {% if lang == "en" %}one Brazilian, one Dutch pilot intervention informed by the comparative model.{% else %}uma intervenção piloto brasileira e uma holandesa informadas pelo modelo comparativo.{% endif %}
